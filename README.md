# ICD 编码知识库

> 基于国家医保局公开数据的 ICD-10/ICD-9/CHS-DRG/DIP 查询与分组工具

[![Python](https://img.shields.io/badge/Python-3.8+-green.svg)](https://www.python.org/)

## 📋 项目简介

本系统是一个**纯前端**的医疗编码知识库查询工具，集成以下功能：

| 功能模块 | 说明 |
|---------|------|
| **ICD-10 查询** | 33,304 条诊断编码，支持医保2.0版与国家临床版对照 |
| **ICD-9 查询** | 13,684 条手术操作编码，支持医保2.0版与国家临床版对照 |
| **CHS-DRG 2.0 分组** | 409 个 ADRG，支持全国版与山西临汾地方版 |
| **DIP 2.0 病种匹配** | 9,520 条核心病种，支持国家版与广东/厦门/连云港地方版 |
| **编码转换** | ICD-10 与 ICD-9-CM-3 双向映射查询 |

### 数据版权说明

所有数据来源于**国家医疗保障局**公开发布的标准：
- 《疾病分类与代码国家临床版 2.0》（ICD-10）
- 《手术操作分类代码国家临床版 2.0》（ICD-9-CM-3）
- 《CHS-DRG 付费技术方案（2.0版）》
- 《按病种分值（DIP）付费病种库（2.0版）》

**本系统仅供学习、研究与教学使用，不构成医疗、法律或行政决策依据。**

详见：[侵权声明.md](./_builder/web/侵权声明.md)

## 🚀 快速开始

### 方式一：直接打开（推荐）

1. 下载本项目 ZIP 文件并解压
2. 双击运行 `_builder/web/启动网页.bat`
3. 浏览器自动打开 http://localhost:8765/


## 📖 功能使用指南

### 1. ICD-10 诊断编码查询

**用途**：查询诊断编码、名称及医保/国标对照

**操作步骤**：
1. 点击「ICD-10」标签页
2. 在搜索框输入编码（如 `A00.0`）或名称（如 `霍乱`）
3. 结果显示：
   - 医保2.0编码与名称
   - 国临版编码与名称
   - 对比差异
   - 是否作为主诊标记

**示例**：
```
输入: A01.0
结果: 伤寒 - 医保编码 A01.0 / 国临编码 A01.0
```

---

### 2. ICD-9 手术操作编码查询

**用途**：查询手术操作编码、名称及类别

**操作步骤**：
1. 点击「ICD-9」标签页
2. 在搜索框输入编码（如 `44.1300x001`）或名称（如 `胃切除术`）
3. 结果显示：
   - 医保2.0编码与名称
   - 国临版编码与名称
   - 操作类别（手术/诊断性操作/治疗性操作/介入治疗）
   - 录入标记

**示例**：
```
输入: 44.1300x001
结果: 胃大部切除术 - 医保编码 44.1300x001
```

---

### 3. CHS-DRG 2.0 分组器

**用途**：根据诊断+手术进行 DRG 分组

**操作步骤**：
1. 点击「DRG」标签页
2. 选择分组版本：
   - **全国 CHS-DRG 2.0**：国家统一标准
   - **山西临汾 CHS-DRG-SX2026**：地方变体
3. 输入主要诊断（ICD-10）
4. 输入主要手术（ICD-9，可选）
5. 添加其他诊断（可选）
6. 点击「查询 DRG 分组」
7. 查看分组结果：
   - 主 ADRG/DRG
   - 备选 ADRG/DRG
   - MCC/CC 标记
   - 分组路径说明

**分组逻辑**：
```
1. 主要诊断 → dx2a 映射 → ADRG
2. 主要手术 → px2a 映射 → ADRG
3. 性别过滤（NO/M 限制）
4. 肿瘤类型对齐
5. MDC 优先级：外科 > 操作 > 内科
6. 歧义处理：诊断/手术 MDC 不一致时手术优先
7. 先期分组：MDCA（移植/呼吸机≥96h/ECMO）
```

**示例**：
```
主诊: A41.9（脓毒症）
主手: 34.0401（气管切开）
结果: MS34 - 脓毒症伴呼吸机支持 >96h
```

---

### 4. DIP 2.0 病种匹配

**用途**：根据诊断+手术匹配 DIP 病种

**操作步骤**：
1. 点击「DIP」标签页
2. 选择分组版本：
   - **国家 DIP 2.0**：9,520 核心病种
   - **广东·梅州 DIP 2.0**：4,477 组
   - **福建·厦门 DIP 2.0**：5,000+ 组
   - **江苏·连云港 DIP 2.0**：5,385 组
3. 输入主要诊断（ICD-10）
4. 输入主要手术（ICD-9，可选）
5. 添加其他诊断（可选）
6. 点击「查询 DIP 入组」
7. 查看病种组与预估支付

**分组逻辑**：
```
1. 主要诊断匹配: d.dx === dx.c
2. 主要手术匹配: d.px === allPx[i].c (权重 3)
3. 相关手术匹配: d.rpx === allPx[i].c (权重 2)
4. 无手术: sc = 1
5. 模糊匹配: 编码前缀匹配 (权重 0.5)
6. 排序: 按得分降序
```

**示例**：
```
主诊: A04.0（大肠杆菌肠炎）
主手: 44.1300x001（胃切除术）
结果: DIP 病种组，分值 317
```

---

### 5. 编码转换

**用途**：ICD-10 与 ICD-9-CM-3 双向映射查询

**操作步骤**：
1. 点击「编码转换」标签页
2. 选择转换方向：
   - ICD-10 → ICD-9
   - ICD-9 → ICD-10
3. 输入编码或名称
4. 查看映射结果

# 侵权声明

## 数据版权说明

### 一、数据来源与版权归属

#### 1. ICD 编码数据
- **ICD-10 诊断编码**: 来源于国家医保局发布的《医疗保障基金结算清单填写规范》及《疾病分类与代码国家临床版 2.0》
- **ICD-9-CM-3 手术编码**: 来源于国家医保局发布的《手术操作分类代码国家临床版 2.0》
- **版权方**: 国家卫生健康委员会、国家医疗保障局

#### 2. DRG 分组数据
- **CHS-DRG 2.0**: 来源于国家医保局发布的《CHS-DRG 付费技术方案（2.0版）》
- **山西临汾 CHS-DRG-SX2026**: 来源于临汾市医疗保障局官方发布的《CHS-DRG-SX2026 分组方案》，基于国家 CHS-DRG 2.0 框架的地方变体
- **版权方**: 国家医疗保障局、山西省临汾市医疗保障局

#### 3. DIP 病种数据
- **国家 DIP 2.0**: 来源于国家医保局发布的《按病种分值（DIP）付费病种库（2.0版）核心病种》
- **广东·梅州 DIP 2.0**: 来源于梅州市医疗保障局官方发布的 DIP 病种库数据
- **福建·厦门 DIP 2.0**: 来源于厦门市医疗保障局官方发布的 DIP 病种库数据
- **江苏·连云港 DIP 2.0**: 来源于连云港市医疗保障局官方发布的 DIP 病种库数据
- **版权方**: 国家医疗保障局、各地医疗保障局

### 二、使用范围

本系统仅供以下用途：
1. 医疗编码学习与培训
2. 医院内部编码查询与核对
3. 医保支付方式研究
4. 学术研究与教学

**禁止用途**：
- 商业用途（包括但不限于收费服务、商业软件集成）
- 修改后重新分发
- 用于任何可能替代官方数据系统的应用

### 三、免责声明

1. **数据准确性**: 本系统提供的数据仅供参考，不构成医疗、法律或行政决策依据。实际应用中请以官方最新发布的数据为准。

2. **更新责任**: 本系统不保证数据的实时更新。医保政策、编码标准可能随时调整，用户应自行核实最新信息。

3. **使用风险**: 因使用本系统数据而产生的任何损失，包括但不限于医疗纠纷、医保结算误差、法律纠纷等，本系统开发者不承担任何责任。

4. **版权归属**: 所有数据版权归原版权方所有。本系统仅作为数据查询工具，不主张任何数据版权。

### 四、引用规范

在学术研究或报告中引用本系统数据时，请注明：
> 数据来源：ICD 编码知识库系统（基于国家医保局公开的 ICD-10、ICD-9-CM-3、CHS-DRG、DIP 数据整理）

如有版权相关问题，请联系：

本声明依据《中华人民共和国著作权法》、《中华人民共和国数据安全法》、《医疗保障基金使用监督管理条例》等法律法规制定。

# 本地医院历史数据 → local_feedback.json 转换脚本

## 使用方法

1. 从贵院 HIS/医保结算系统导出历史病例 CSV，格式参考下面的模板
2. 修改 `source_columns` 为你实际 CSV 的列名
3. 运行 `python import_local_feedback.py your_export.csv`

## CSV 模板

```csv
住院号,入院日期,出院日期,主要诊断编码,主要诊断名称,其他诊断编码,主要手术编码,手术名称,住院天数,总费用,付费方式,医保反馈病组编码,医保反馈病组名称,医保反馈权重/分值,医保反馈是否MCC,医保反馈是否CC
ZYH001,2025-01-15,2025-01-22,D25.900,子宫肌瘤,,35.3100,子宫肌瘤剔除术,7,8500,1,NZ19,子宫系统良性肿瘤,1.023,0,0
ZYH002,2025-02-10,2025-02-18,J06.900,急性上呼吸道感染,,无,3,1200,2,RA01,急性上呼吸道感染,0.456,0,0
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 住院号 | 唯一标识 |
| 主要诊断编码 | ICD-10 编码（4位前缀用于匹配） |
| 医保反馈病组编码 | 国家医保实际入组结果 |
| 医保反馈是否MCC | 1=有MCC，0=无 |
| 医保反馈是否CC | 1=有CC，0=无 |

## 运行

```bash
python import_local_feedback.py your_export.csv
# 输出: _builder/web/local_feedback.json
```

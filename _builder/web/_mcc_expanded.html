MCC 严重合并症/并发症 — 临床诊断标准速查（按ICD-10章节）
MCC (Major Complication/Comorbidity) — 严重合并症/并发症，CHS-DRG 2.0 共收录 4,477条。命中后DRG后缀为 1，支付权重显著提高。以下按ICD-10章节逐一列出主要MCC病种及临床诊断标准。
第1章 A00-B99 某些传染病和寄生虫病
脓毒症 (Sepsis) · A41.9, A40-A41
A41.9脓毒症（未特指）
A40.9链球菌性脓毒症
A41.5革兰阴性菌脓毒症
诊断标准 (Sepsis-3): 明确/可疑感染 + SOFA评分急性升高≥2分（呼吸PaO₂/FiO₂、凝血PLT、肝脏Bil、循环MAP/升压药、神经GCS、肾脏Cr/尿量）。qSOFA快速筛查（≥2项）：RR≥22、SBP≤100mmHg、GCS<15。感染性休克: 脓毒症 + 充分液体复苏后仍需升压药维持MAP≥65mmHg + 血乳酸>2mmol/L（病死率>40%）
感染性休克 · R57.2
R57.2感染性休克
脓毒症子集：持续性低血压需升压药 + 血乳酸>2mmol/L 尽管充分液体复苏。区别于R57.1低血容量性休克/R57.0心源性休克。
中枢神经系统感染 · G00-G07
G00.9细菌性脑膜炎
G03.9脑膜炎（未特指）
G04.9脑炎/脊髓炎
G06.0颅内脓肿
细菌性脑膜炎: CSF白细胞>1000×10⁶/L（中性粒为主）+ 蛋白↑+ 糖↓+ 革兰染色/培养(+) + 脑膜刺激征(颈强直/Kernig/Brudzinski)。脑炎: 发热+意识障碍+CSF淋巴细胞↑+ MRI颞叶异常信号+ HSV-PCR(+)
结核病（重症） · A15-A19
A15.0肺结核（痰检阳性）
A17.0结核性脑膜炎
A19.9粟粒性结核
结核性脑膜炎: CSF淋巴细胞↑+蛋白↑+糖↓+ ADA↑+ T-SPOT(+) + 影像学基底池强化。粟粒性结核: 弥漫性粟粒样结节（胸片/CT）+ 多器官受累+ 病原学/分子检测(+)。脑膜炎与粟粒性为MCC级
HIV相关机会性感染 · B20-B24
B20.0HIV伴分枝杆菌感染
B20.4HIV伴卡波西肉瘤
B20.5HIV伴其他真菌病
B22.7HIV导致多系统疾病
CD4<200 + 出现AIDS定义性疾病（机会性感染/恶性肿瘤）→ AIDS期。上述编码均属MCC级（AIDS合并严重并发症，医疗资源消耗极大）
感染性心内膜炎 · I33.0, I39
I33.0急性和亚急性感染性心内膜炎
I33.9急性心内膜炎
改良Duke标准: 主要标准：血培养2次阳性(典型病原体) + 超声心动图赘生物/脓肿/瓣膜穿孔。次要：发热>38°C + 栓塞现象 + 免疫现象(Osler结节等) + 血培养1次阳性。确诊需2主/1主+3次/5次
破伤风 · A33-A35
A35其他破伤风
肌肉痉挛（牙关紧闭→苦笑面容→角弓反张）+ 自主神经不稳定（高血压/心动过速）。可发生呼吸衰竭需机械通气，属MCC
严重病毒性出血热 · A96-A99
A98.5出血热伴肾综合征
A99未特指的病毒性出血热
发热+出血倾向(血小板↓)+毛细血管渗漏+多器官功能损害。肾综合征型：发热期→低血压休克期→少尿期(AKI)→多尿期→恢复期
第2章 C00-D49 肿瘤（恶性肿瘤严重并发症）
肿瘤溶解综合征 · C80+E88.3
E88.3肿瘤溶解综合征(TLS)
Cairo-Bishop标准: 化疗后7d内出现≥2项：尿酸≥476μmol/L(或↑25%)、K⁺≥6.0mmol/L(或↑25%)、P≥1.45mmol/L(或↑25%)、Ca²⁺≤1.75mmol/L(或↓25%)。临床TLS: 实验室TLS + AKI(Scr↑)/心律失常/抽搐/猝死。属MCC级
恶性肿瘤脑转移 · C79.3
C79.3脑/脑膜继发性恶性肿瘤
MRI/CT示颅内占位性病变（多发常见）+ 原发肿瘤病史+ 临床表现：颅内高压(头痛呕吐视乳头水肿)+局灶神经功能缺损+癫痫。需增强MRI鉴别，大水肿+中线移位=MCC级
上腔静脉综合征 · C80+I87.1
I87.1上腔静脉综合征
面部/颈部/上肢水肿+颈静脉怒张+胸壁静脉曲张+呼吸困难/端坐呼吸+咳嗽声嘶。通常由纵隔恶性肿瘤(肺癌/淋巴瘤)压迫所致，属肿瘤急症，MCC级
恶性胸腔积液 · C78.2+J91
J91恶性肿瘤引起的胸腔积液
胸水细胞学阳性或胸膜活检阳性。大量胸水导致呼吸困难/压迫性肺不张。与良性胸水区分：LDH↑、蛋白↑、pH<7.3、CEA↑
脊髓压迫症 · C79.4+G95.8
G95.8脊髓压迫症（肿瘤转移）
椎体转移+硬膜外占位+进行性背痛(夜间加重)+感觉平面/运动障碍/括约肌功能障碍。MRI示脊髓受压变形。属肿瘤急症需24h内处理，MCC级
高钙血症(肿瘤性) · E83.5
E83.5高钙血症（肿瘤相关）
校正Ca²⁺>2.75mmol/L(或离子钙>1.35)+ PTHrP↑/溶骨性转移。临床表现：恶心呕吐/多尿/便秘/意识障碍(高钙危象>3.5mmol/L需紧急降钙)。常伴AKI，MCC级
第3章 D50-D89 血液及造血器官/免疫疾病
DIC 弥散性血管内凝血 · D65
D65弥散性血管内凝血(DIC)
ISTH显性DIC评分≥5分： ①PLT(>100=0, 50-100=1, <50=2) ②FDP/D-二聚体(无↑=0, 中度↑=2, 显著↑=3) ③PT延长(<3s=0, 3-6s=1, >6s=2) ④纤维蛋白原(>1g/L=0, <1g/L=1)。出血+血栓并存，死亡率30-50%，属MCC
粒细胞缺乏症 · D70
D70粒细胞缺乏症
诊断标准: ANC(中性粒细胞绝对计数)<0.5×10⁹/L。ANC<0.1为极重度（MCC级）。常见于化疗后、药物反应。核心风险：严重感染（发热>38.3°C+ANC<0.5→粒缺发热，需紧急抗感染，属肿瘤急症）
重型再生障碍性贫血 · D61.9
D61.9再生障碍性贫血（未特指）
重型SAA（Camitta标准）: 骨髓有核细胞<25% + 外周血≥2项：ANC<0.5×10⁹/L、PLT<20×10⁹/L、网织红<20×10⁹/L。免疫抑制/造血干细胞移植。SAA为MCC级
溶血性尿毒症综合征 · D59.3
D59.3溶血性尿毒症综合征(HUS)
三联征: 微血管病性溶血性贫血(Hb↓+裂红细胞↑+LDH↑+haptoglobin↓)+血小板减少+AKI。典型HUS：腹泻(大肠杆菌O157:H7)+血便→HUS。属MCC级，需血浆置换/透析
血栓性血小板减少性紫癜 · M31.1
M31.1血栓性血小板减少性紫癜(TTP)
五联征（严重型）: ①微血管病溶血 ②PLT↓ ③发热 ④神经系统异常(头痛/意识障碍) ⑤肾损害。ADAMTS13活性<10%(获得性/先天性)。死亡率>90%不治疗，属MCC，需紧急血浆置换
重症免疫缺陷 · D80-D84
D80-D84免疫缺陷综合征（各类）
IgG<3g/L+反复严重感染→CVID；联合免疫缺陷(SCID)：T/B细胞功能丧失+婴儿期严重感染。骨髓移植/免疫重建治疗中，属MCC级
第4章 E00-E89 内分泌、营养和代谢疾病
糖尿病酮症酸中毒(DKA) · E10.0-E11.0
E11.02型糖尿病伴酮症酸中毒
诊断标准: 血糖>13.9mmol/L(>250mg/dL) + 酮体(血/尿≥++)+ pH<7.3 + HCO₃⁻<15mmol/L + 阴离子间隙>12。重度DKA: pH<7.0或HCO₃⁻<5→MCC级，死亡率>5%，需ICU
高渗性高血糖状态(HHS) · E11.1
E11.12型糖尿病伴高渗性昏迷
诊断标准: 血糖>33.3mmol/L(>600mg/dL) + 血浆渗透压>320mOsm/L + 意识障碍(昏睡/昏迷) + 无明显酮症(pH>7.3)。计算: 渗透压=2×Na⁺+Glu+BUN(mmol/L)。死亡率10-20%，MCC级
低血糖昏迷 · E15-E16.2
E15非糖尿病性低血糖昏迷
血糖<2.8mmol/L(<50mg/dL)+意识障碍(昏迷/GCS<15)+ Whipple三联征：低血糖症状+低血糖值+补糖后恢复。反复严重低血糖可致不可逆脑损伤，MCC级
甲状腺危象 · E05.9+E05.5
E05.5甲状腺危象（甲亢危象）
Burch-Wartofsky评分≥45分: 高热>40°C + 心动过速>140 + CHF/肺水肿 + 房颤 + 意识障碍(谵妄/昏迷) + 消化系统(腹泻呕吐黄疸) + 诱因(感染/手术/停药)。死亡率10-30%，MCC级
肾上腺危象 · E27.2
E27.2肾上腺危象(Addisonian crisis)
低血压+低钠+高钾+低血糖+嗜酸粒细胞↑。诱因：感染/手术/应激/停药。诊断：血皮质醇<3μg/dL(确认)+ ACTH升高。紧急使用氢化可的松，延误可致死，MCC级
严重电解质紊乱 · E87
E87.5高钾血症(>6.5mmol/L)
E87.1低钠血症(<120mmol/L重症)
E87.0高钠血症(>160mmol/L危重)
E87.8其他电解质紊乱
高钾危象: K⁺>6.5 + ECG改变(尖T/宽QRS/P波消失/正弦波)→立即静推钙剂+降钾。低钠重症: Na⁺<120 + 脑水肿(意识障碍/抽搐/昏迷)→3%高渗盐水缓慢纠正(速度<10mmol/L/24h防ODS)。高钠危象: Na⁺>160 + 脑细胞脱水+意识障碍
严重营养不良 · E40-E46
E41营养性消瘦（重度）
E43未特指的重度营养不良
重度营养不良（GLIM标准）: BMI<18.5(亚裔<17) + 体重下降>10%(6月内) + 肌肉量减少(CT/BIA评估) + 炎症/疾病负担。伴低蛋白血症(ALB<28g/L)属MCC级
第6章 G00-G99 神经系统疾病
昏迷 · R40.2, G93.5脑疝
R40.2昏迷(GCS≤8)
G93.5脑疝（经小脑幕/枕骨大孔）
GCS(格拉斯哥评分): ≤8→深昏迷(需气管插管)，3-8为重度意识障碍，MCC级。脑疝: 瞳孔散大固定(单侧→双侧)+去脑强直+Cushing反应(血压↑心率↓呼吸不规)→数小时内可致死，紧急神经外科处理。均属MCC
癫痫持续状态 · G41.9
G41.9癫痫持续状态(≥30min)
定义: 抽搐持续>5分钟或≥2次发作间意识不恢复(>30分钟为传统定义)。难治性SE: 一线(苯二氮卓)+二线(丙戊酸/左乙拉西坦/苯巴比妥)无效→需麻醉剂(丙泊酚/咪达唑仑)+ EEG监测。SE>30min→MCC级，死亡率10-20%
吉兰-巴雷综合征 · G61.0
G61.0吉兰-巴雷综合征(GBS)
诊断标准 (Brighton): 对称性肢体无力(下肢→上肢)→脑神经受累(面瘫/吞咽困难)+腱反射消失+ CSF蛋白-细胞分离(蛋白↑+WBC正常)。重症: 呼吸衰竭(FVC<20mL/kg→机械通气)+自主神经功能障碍(心律失常/血压波动)，需ICU+PE/IVIG，MCC级
重症肌无力危象 · G70.0
G70.0重症肌无力(伴危象)
肌无力突然加重(球麻痹/呼吸肌无力)→FVC进行性下降(<15-20mL/kg)+ CO₂潴留→需气管插管+机械通气(NIPPV无效应时)。可因感染/药物/手术诱发。需PE/IVIG，MCC级
急性脊髓炎 · G37.3
G37.3急性横贯性脊髓炎
诊断标准: 双侧感觉/运动/自主神经功能障碍（明确感觉平面）+ MRI脊髓异常信号+ CSF细胞/蛋白↑+ 排除压迫/缺血/感染。快速进展→完全性截瘫+尿潴留属MCC级。排除视神经脊髓炎(NMOSD:AQP4-Ab)
脑卒中(重症) · I61-I63,G45
I61.9脑出血(大面积/破入脑室)
I63.5脑梗死(大面积伴脑水肿)
大面积脑梗死: 梗死体积>145cm³(DWI)或占位性脑水肿+中线移位>5mm+意识恶化→恶性MCA梗死(死亡率80%未经减压)。脑出血重症: 出血量>30mL(幕上)或>5mL(幕下)+破入脑室+GCS下降→MCC级
第9章 I00-I99 循环系统疾病
AMI 急性心肌梗死 · I21-I22
I21.9急性心肌梗死（未特指）
I22.9再发心肌梗死
第4版全球定义: hs-cTn↑/↓(>99百分位URL) + ≥1项：①胸痛 ②新发缺血性ECG改变(ST-T/新LBBB) ③病理性Q波 ④影像学新发心肌失活/室壁运动异常 ⑤冠脉造影/尸检血栓。STEMI: ST段抬高≥2导联→紧急PCI(<90min)。MCC级
心源性休克 · R57.0
R57.0心源性休克
诊断标准 (SHOCK试验): SBP<90mmHg持续>30min 或 需升压药维持SBP≥90 + 末梢灌注不足(肢冷/尿少<30mL/h/意识改变) + CI<2.2L/min/m² + PCWP>15mmHg。最常见于AMI后(LVEF<40%)，死亡率>50%，MCC级
心脏骤停/室颤 · I46.0-I49.0
I46.0心脏骤停（成功复苏）
I49.0心室颤动/扑动
心脏骤停: 意识丧失+无脉搏+无有效呼吸+心电示波：室颤/无脉室速/心室停搏/PEA。CPR+除颤+肾上腺素+亚低温治疗。I46.0需记录"成功复苏"(ROSC恢复自主循环)，属MCC
主动脉夹层 · I71.0
I71.0主动脉夹层（任何部位）
Stanford分型: A型(累及升主动脉)→紧急手术，48h内死亡率>50%未手术; B型(降主动脉)→血压控制。典型表现: 撕裂样胸背痛+双上肢血压差>20mmHg+主动脉瓣反流杂音。CTA/TEE确诊。MCC级
IMH(壁间血肿)/PAU(穿透性溃疡): 属急性主动脉综合征，同样MCC
急性肺栓塞（大面积） · I26.9
I26.9肺栓塞（未特指急性/慢性）
大面积(高危)PE: sBP<90mmHg持续>15min或需升压药+ 影像(CTPA/通气灌注)证实栓塞 + 右室功能障碍(超声：McConnell征/RV/LV>1)。中危: sBP正常+RV功能障碍+肌钙蛋白↑→溶栓/抗凝/导管介入。大面积PE为MCC级，死亡率>30%
急性心力衰竭（重度） · I50.1-I50.9
I50.1急性左心衰竭（肺水肿）
I50.9心力衰竭（心功能IV级）
NYHA IV级: 休息时仍有心衰症状+不能从事任何体力活动。Killip III-IV级(AMI后心衰): 双肺湿啰音>50%+心源性休克。Forrester IV型: CI<2.2+PCWP>18→需正性肌力药/IABP/机械循环支持。三者均属MCC级
心脏压塞 · I31.9
I31.9心脏压塞（心包积液）
Beck三联征: 低血压+颈静脉怒张+心音低钝。超声: 心包积液+右房/右室舒张期塌陷+二尖瓣/三尖瓣血流呼吸变异>30%。奇脉: 吸气时SBP下降>10mmHg。需紧急心包穿刺引流，MCC级
高血压危象/恶性高血压 · I10-I16
I16.0高血压急症(危象)
高血压急症: sBP>180或dBP>120 + 靶器官损害：脑(脑病/脑出血/卒中)+心脏(心衰/ACS)+肾(AKI)+主动脉夹层+视网膜(出血/渗出/视乳头水肿)。恶性高血压: 双侧视网膜出血+渗出+视乳头水肿，MCC级。需IV降压
第10章 J00-J99 呼吸系统疾病
ARDS 急性呼吸窘迫综合征 · J80
J80急性呼吸窘迫综合征(ARDS)
柏林定义(2012): ①急性起病(<1周) ②双肺浸润影(胸片/CT) ③非心源性(无心衰证据/液体超负荷) ④PaO₂/FiO₂：轻度200-300(面罩吸氧)、中度100-200(需PEEP≥5)、重度<100→MCC级。死亡率：轻度27%→中32%→重45%
急性呼吸衰竭 · J96.0
J96.0急性呼吸衰竭
Ⅰ型呼衰(氧合障碍): PaO₂<60mmHg(海平面吸空气)+ PaCO₂正常或↓。Ⅱ型呼衰(通气障碍): PaO₂<60+ PaCO₂>50+ pH<7.35(急性失代偿)。需机械通气 (>24h): 无创(NIPPV)或有创(气管插管)均属MCC级。pH<7.25→紧急插管
张力性气胸 · J93.0
J93.0张力性气胸

MCC/CC 排除与使用规则说明：
1. 诊断冲突排除：当其他诊断与主要诊断存在排除表(exclusion table)关系时，该诊断不作为MCC/CC计费（如孕产期O编码与新生儿P编码互为排除）
2. MCC表与CC表独立运作：每条MCC/CC编码有独立的排除表(mcc_tbl/cc_tbl)，仅当主诊断也在该排除表中时才被排除
3. 不作为主诊的编码：标记为"不作为主诊"的诊断编码可用于其他诊断参与MCC/CC判定
4. CHS-DRG 2.0 统计：MCC共4,477条，CC共8,008条；MCC命中后DRG后缀为1（伴严重合并症），显著影响支付权重
5. 输入框实时标注：在DRG诊断搜索框输入编码时，系统自动标注MCC / CC标签
6. 以上诊断标准仅供临床参考，具体MCC判定以医保结算清单填写规范和国家医保局CHS-DRG 2.0分组方案为准

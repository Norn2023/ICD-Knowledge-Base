# 激光疗法知识

## 概述

激光疗法（Laser Therapy）是利用激光的生物学效应进行治疗的方法。根据激光功率和作用机制的不同，分为**高能量激光治疗**（破坏性、手术类）和**低强度激光治疗 / LLLT**（理疗类、非破坏性）。

---

## 一、低强度激光治疗（LLLT / 冷激光）

**定义**：使用低功率激光（通常 <500mW），不会造成组织温度明显升高或凝固坏死，属于光生物调节作用（Photobiomodulation）。

**适用仪器**：He-Ne激光、半导体激光（GaAs/GaAlAs）、Nd:YAG激光（低功率模式）

**核心参数**：
- 波长范围：600-1000nm（红光至近红外）
- 输出功率：5-500mW
- 能量密度：1-10 J/cm²
- 作用深度：0.5-3cm（取决于波长和功率）

### 1.1 氦氖激光（He-Ne Laser）

| 参数 | 说明 |
|------|------|
| **波长** | 632.8nm（可见红光） |
| **功率** | 1-50mW（典型值5-20mW） |
| **仪器** | 氦氖激光治疗仪（气体激光器） |
| **原理** | 低强度红光照射皮肤/黏膜，通过线粒体细胞色素C氧化酶吸收光能，促进ATP合成、改善微循环、抗炎、促进组织修复 |
| **穿透深度** | 约0.5-1cm（浅表组织） |
| **照射方式** | 原光束照射、散焦照射、光纤传导 |

### 1.2 半导体激光（Semiconductor Diode Laser）

| 参数 | 说明 |
|------|------|
| **波长** | 650nm（红光）、808nm/810nm/830nm（近红外）、904nm/980nm（红外） |
| **功率** | 10-500mW |
| **仪器** | 半导体激光治疗仪（GaAs/GaAlAs激光二极管） |
| **原理** | 近红外激光穿透更深（2-3cm），作用于深层组织的线粒体，促进ATP合成、改善血液循环、镇痛、抗炎 |
| **穿透深度** | 1-3cm（近红外波段穿透更深） |

### 1.3 适应症与对应 ICD-10 编码

| 适应症 | ICD-10 编码 | 激光类型 |
|--------|------------|----------|
| 皮肤溃疡 | L98.4 | He-Ne、半导体 |
| 褥疮/压力性溃疡 | L89 | He-Ne、半导体 |
| 伤口愈合不良 | T14.1/L98.4 | He-Ne、半导体 |
| 带状疱疹 | B02 | He-Ne |
| 疖肿/痈 | L02 | He-Ne |
| 过敏性皮炎 | L23/L30 | He-Ne |
| 关节疼痛/关节炎 | M25.5/M19 | 半导体（近红外） |
| 软组织损伤 | M79.8/Sxx | 半导体 |
| 慢性疼痛 | R52/G89 | 半导体 |
| 颞下颌关节紊乱 | K07.6 | He-Ne、半导体 |
| 口腔溃疡 | K12.0 | He-Ne |
| 静脉炎/血栓性静脉炎 | I80 | 半导体 |
| 糖尿病足 | E11.5（伴周围循环并发症） | He-Ne、半导体 |
| 瘢痕/瘢痕疙瘩 | L91.0/L90.5 | 半导体 |

### 1.4 禁忌症

- 恶性肿瘤部位（光生物调节可能促进肿瘤生长）
- 妊娠期腹部照射
- 光过敏/光敏感性疾病
- 活动性出血部位
- 眼睛直接照射（需防护镜）

## 二、高能量激光治疗

**定义**：使用高功率激光，通过热效应使组织凝固、汽化或切割，属于手术类操作。

### 2.1 脉冲激光（Pulsed Laser / 调Q激光）

| 参数 | 说明 |
|------|------|
| **波长** | 532nm（倍频Nd:YAG绿光）、694nm（红宝石）、755nm（翠绿宝石）、1064nm（Nd:YAG） |
| **原理** | 选择性光热作用（Selective Photothermolysis），极短脉冲（ns-ms级）使靶组织（色素、血管）选择性破坏而不损伤周围组织 |
| **适应症** | 血管性疾病（鲜红斑痣）、色素性疾病（太田痣、雀斑）、纹身去除 |
| **ICD-10** | L81.7（色素性紫癜性皮肤病）、Q82.5（先天性非肿瘤性痣）、D22（黑色素细胞痣） |
| **仪器** | 调Q Nd:YAG激光、脉冲染料激光、翠绿宝石激光 |

### 2.2 二氧化碳激光（CO2 Laser）

| 参数 | 说明 |
|------|------|
| **波长** | 10600nm（远红外） |
| **原理** | 水分子强烈吸收CO2激光能量，导致组织瞬间汽化，用于切割和消融 |
| **穿透深度** | <0.1mm（极浅，精确可控） |
| **适应症** | 各类皮肤良性肿物、疣、鸡眼、瘢痕修整、妇科宫颈病变 |
| **ICD-10** | B07（病毒疣）、L72（皮脂腺囊肿）、L84（鸡眼）、N87（宫颈发育不良） |

### 2.3 Nd:YAG激光（高功率模式）

| 参数 | 说明 |
|------|------|
| **波长** | 1064nm（近红外） |
| **原理** | 热凝固为主，也可用于切割，穿透深度大 |
| **适应症** | 血管瘤、鼻腔出血、前列腺增生、膀胱肿瘤、消化道止血 |
| **ICD-10** | D18.0（血管瘤）、R04.0（鼻出血）、N40（前列腺增生）、D41.4（膀胱肿瘤） |

## 三、激光针（Laser Acupuncture）

| 参数 | 说明 |
|------|------|
| **定义** | 用低强度激光束代替传统毫针刺激穴位 |
| **对应立项指南** | 仪器针法（#190） |
| **对应技术规范** | PBCD0011 激光针治疗 |
| **波长** | 632.8nm（He-Ne）或 650-830nm（半导体） |
| **功率** | 1-10mW（低于LLLT理疗功率） |
| **原理** | 低强度激光束对准穴位，以激光能量代替针刺的机械刺激，通过光生物调节作用调节经络和脏腑功能 |
| **ICD-10** | 对应所治疗疾病的编码（激光针本身不是疾病，是治疗手段） |
| **ICD-9-CM3** | 无独立编码（属于物理疗法 93.3900x001 范畴，但已去除此映射） |

**与激光疗法的区别**：
- 激光针：对准特定穴位，功率极低（1-10mW），治疗时间短（数十秒至数分钟）
- 激光疗法（LLLT）：照射病变区域，功率较高（5-500mW），治疗时间较长

# 各省市医疗服务价格映射文件

## 文件存放说明

### 目录结构
```
_builder/price-mapping/
├── README.md          ← 你在这里看使用说明
├── 上海市/             ← 每个省份一个文件夹
│   ├── 映射关系.xlsx   ← 官方Excel/CSV
│   └── 其他附件.pdf
├── 北京市/
│   └── ...
└── ...
```

### 支持的文件格式

| 格式 | 说明 |
|------|------|
| **PDF** | 政府官网下载的正式文件，我能直接读取文字 |
| **Excel (.xlsx)** | 表格数据，我能解析列内容 |
| **Word (.docx)** | 文档类文件 |
| **图片 (PNG/JPG)** | 纸质文件扫描或拍照，我会 OCR 识别 |
| **CSV/TXT** | 纯文本表格 |

### 每条映射需要的字段（至少包含）

| 字段 | 必须 | 示例 |
|------|------|------|
| 上海项目编码 | ✅ | `331305010` |
| 上海项目名称 | ✅ | `子宫切除术` |
| 立项指南编号/名称 | ✅ | `430` 或 `子宫切除术` |
| 技术规范编码/名称 | ✅ | `HTR6X701` 或 `子宫切除术` |
| ICD-9编码 | ✅ | `71.5x00x001` |

**可选字段**：匹配分数、备注、生效日期等

### 使用方法

1. 把官方文件放到对应省份的文件夹里
2. 告诉我文件名，我来解析提取
3. 解析完成后会生成 `cross_refs.json` 更新到 `_builder/4way-mapping/data.json`

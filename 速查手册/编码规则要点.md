# 编码规则要点

> ICD-10 / ICD-9 核心编码规则汇总。

---

## ICD-10 疾病诊断编码规则

### 1. 基本原则

- 每个诊断对应**一个最具体编码**
- 有亚目（小数点后）时不得只编类目
- 症状 + 明确病因 → 只编码病因

### 2. 双重分类（剑号 † 星号 * 系统）

```
举例：糖尿病性肾病
    E11.2†  2型糖尿病伴肾脏并发症  ← 剑号（病因）
    N08.3*  肾小球疾病      ← 星号（表现）
```

- **剑号 †** = 病因编码（主要编码）
- **星号 \*** = 表现编码（附加编码）

### 3. 肿瘤编码规则

```
形态学M码: /0 良性  /1 未定  /2 原位  /3 恶性  /6 转移

步骤：① 查形态学确定 M 码
      ② 根据 M 码决定章（C 恶性 / D 良性等）
      ③ 查部位编码
```

详见 [[ICD10-疾病诊断/02-肿瘤(C00-D48)/_index\|第二章 肿瘤]]

### 4. 损伤中毒编码

- **S 编码**：具体损伤部位
- **T 编码**：多部位损伤 + 中毒
- 外因编码（V01-Y98）**必须另编**作为附加编码

### 5. 合并编码

多个相关诊断可合并为一个编码：

| 分开诊断 | 合并编码 |
|---------|---------|
| 高血压 + 心脏病 | I11.- 高血压心脏病 |
| 糖尿病 + 肾病 | E10-E14 第四位 .2 |
| 慢性肾衰竭 + 高血压 | I12.0 |

### 6. "不包括"规则

每个章节的"不包括"（Excludes）决定了编码归属，**必须先看**。

## ICD-9 手术操作编码规则

### 1. 基本原则

- 按**手术目的**分类，而非解剖部位
- 诊断性 > 治疗性（同类操作）
- 编码优先选择**最具体**的细目

### 2. 同时进行的操作

- 一个手术目的 + 多个步骤 → 只编主要手术编码
- 不同目的的操作 → 分别编码

### 3. 内镜/腹腔镜操作

- 内镜下操作 → 原手术编码 + 内镜辅助编码
- 腹腔镜转开腹 → 按开腹编码

### 4. 介入操作

- 诊断性造影 → 88.5-
- 治疗性介入 → 按照具体操作编码
- 血管成形、支架置入 → 00.5- / 00.6-

### 5. 双侧操作

- 双侧手术（如疝修补） → 注明双侧
- 部位对称的手术 → 按实际情况编码

## 常见误区

| 错误做法 | 正确做法 |
|---------|---------|
| 症状和病因同时编 | 只编病因，除非病因不明 |
| 肿瘤只编部位码 | 必须同时编形态学 M 码 |
| 损伤不编外因码 | 损伤中毒必须附加 V-Y 编码 |
| 手术只写名称不查编码 | 手术名称≠ICD-9 编码术语 |
| 术后诊断用手术名称 | 术后诊断 ≠ 手术操作名称 |

---

## 编码思维口诀

> **先查章，再查节，最后定编码**
> **有具体不用笼统，有合并不用分开**
> **肿瘤一定要查 M，损伤别忘了外因**
> **手术按目的来分类，不是按部位来硬背**

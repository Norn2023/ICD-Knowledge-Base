# ICD-10 疾病诊断编码 总索引

> ICD-10（International Classification of Diseases, 10th Revision）国际疾病分类第 10 次修订本，共 **22 章**。

## 编码结构

```
A  A0  A00  A00.0  A00.0xx
│   │    │     │       └── 扩展码
│   │    │     └────────── 亚目（小数点后1位）
│   │    └──────────────── 类目（3位码）
│   └─────────────────── 节（2位码）
└─────────────────────── 章（字母开头）
```
